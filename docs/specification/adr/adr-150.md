# ADR-150: A Duration Is `std::time::Duration`, and It Is Written `5.seconds()`

**Status:** Accepted · **Built:** yes — see §5
**Date:** September 19, 2026
**Target Version:** Nikaia 0.0.31
**Related:** [ADR-141](adr-141.md) D2 (which marked the page *unspecified*),
[ADR-285](adr-285.md) (no suffix on a number literal, and why),
[ADR-285](adr-285.md) (a literal takes its type from its use),
[ADR-288](adr-288.md) D11 (an entry exists because a program asked for it),
Part II 12.4, Part III 13.3 (`cleanup-deadline`, which is already a duration
in a manifest)

## 1. Context

Part II 12.4's `sleep(5.seconds())` writes a value of a type nothing declares,
and [ADR-141](adr-141.md) D2 marked it *unspecified*. The type is not in
dispute — a duration is a duration — so what is left is where it lives and how
it is spelled.

The manifest already has one: `cleanup-deadline` is a duration a person writes
in a `.toml`. What has never existed is the value a program holds.

## 2. Decisions

### D1 — The type is `std::time::Duration`.

A `std` type, not a language one. It carries a span of time and nothing else,
it is a value that copies, and it is what `sleep`, a timeout and a deadline
take.

### D2 — It is written `5.seconds()`, as a method on an integer.

```nika
sleep(5.seconds())
sleep(250.millis())
let deadline = 2.minutes()
```

An extension `std::time` provides — `seconds`, `millis`, `micros`, `minutes`,
`hours` on the integer types — beside the constructors
(`Duration::seconds(5)`) for a computed count.

**It is what the pages already write**, which is not a small argument: the
spelling was chosen by whoever wrote the example, and it reads the way the
sentence does.

### D3 — There is no suffix literal, and that is [ADR-285](adr-285.md) kept.

`5s` and `250ms` would be a literal form that record declined for numbers, on
the ground that *the digits a number is written in are a spelling and the use
gives the type*. Reopening it for one type would make the rule *a literal has
no suffix, except for durations* — and a rule with an exception in it is a
rule a reader has to remember rather than one they can apply.

### D4 — It is `std`'s, so the language learns nothing.

No keyword, no literal, no type in the grammar. What this costs the **language**
is nothing at all; what it costs `std` is a type and a trait implementation.

## 3. Consequences

* Part II 12.4's `sleep(5.seconds())` becomes a program, and the mark leaves
  the page for that half of it.
* [ADR-292](adr-292.md)'s `select` has the value its timeout arm needs.
* The literal rule stays whole.
* **What it costs:** one `std` type, its entries, and the integer extension.

## 4. What this does not decide

* **A clock**: what *now* is, and whether it is monotonic. A duration is a
  span; an instant is a different value and a different question.
* **A duration in a manifest becoming this type.** `cleanup-deadline` is read
  by the build, not by a program, and the two meeting is a question nobody has
  asked.
* **Arithmetic on durations** beyond what the type obviously has; the entries
  exist because a program asked ([ADR-288](adr-288.md) D11).

## 5. What is built

All of it.

1. **`std::time::Duration` and its entries.** The type is re-exported rather
   than wrapped — a wrapper would be a second type with the same meaning — and
   it carries `crosses = true`, which is an easy claim: a span is a number of
   ticks.
2. **The integer extension, five names.** Ten entries rather than five, because
   Part I 2.2 offers two integer types
   ([ADR-285](adr-285.md)): `5` is an `i32` where nothing asks otherwise and a
   count that came from a length is an `i64`, so a file holding both needs both
   halves. A count below zero is **no time at all** rather than an abort, and a
   count too large to multiply **stops** rather than wrapping into a short wait.
3. **`sleep` taking one**, and it is a suspension point: the missing `sync` line
   in the ledger, and the `.await` in the generated Rust.
4. **Part II 12.4's line as a test that runs** — shortened, because a test that
   waits five seconds is a test people learn to skip. Beside it, the promise the
   line is *for*: a task started before the wait has its value when the wait is
   over, on the one thread `user_parallelism = no` gives a program.

**What the constructors are not.** D2 names `Duration::seconds(5)` beside the
extension, for a computed count. It is not built, because §4's own rule is
[ADR-288](adr-288.md) D11's — *the entries exist because a program asked* — and
no program has: `count.seconds()` is what a computed count is already written
as.

### What it found

**A duration was a type that moves.** `keeps::moves` names what copies, and a
type it does not name is lent — so the first program to write
`sleep(50.millis())` got a `&` in front of its argument, and `rustc` spoke about
the generated file (Part III C.1). The same defect [ADR-302](adr-302.md) D6
found one type over, met again because the copy list is a list.

**And it decided how a bare `std` name is keyed.** `sleep` is written bare, so
its entry is `sleep` and not `time::sleep` — which is what `print` and `println`
already were. The alternative was to have the emitter resolve a bare call
name-for-name into `std`, and that is the emitter **guessing**: a unit built
from `--input` does not carry the ledger of the package beside it, so
`examples/inventory`'s own `read` would find `fs::read` and take an `.await` for
a function that is not a future. Measured, not reasoned about — the example's
committed lowering changed. [#93](https://github.com/Nikaia-Language/Nikaia/issues/93) carries the wider version of
that gap.
